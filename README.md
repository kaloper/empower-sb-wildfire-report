# EMPOWER Santa Barbara Wildfire Preparedness Survey

This repository contains the public-facing EMPOWER Santa Barbara wildfire
preparedness survey report.

## View the report

After GitHub Pages is enabled:

`https://YOUR-GITHUB-USERNAME.github.io/empower-sb-wildfire-report/`

## Published files

- `index.html`: interactive report
- `vendor/leaflet/`: local Leaflet JavaScript, CSS, and images
- `figures/`: public aggregate figures
- `tables/`: approved aggregate result tables
- `.nojekyll`: disables Jekyll processing

## Enable GitHub Pages

1. Open the repository on GitHub.
2. Select **Settings**.
3. Select **Pages**.
4. Choose **Deploy from a branch**.
5. Select the `main` branch.
6. Select `/ (root)`.
7. Save.

## Privacy

This repository should contain only public aggregate results. Do not commit
raw survey records, participant identifiers, residential coordinates,
addresses, household-level spatial data, passwords, API keys, or restricted
board files.
